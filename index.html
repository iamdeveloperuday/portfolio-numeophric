02 The person behind the code

Curiosity turned into code.

I’m a Class 12 Computer Science student in Nepal. I got into programming through Scratch, where I earned an MST certification in block-based programming, and I kept going: HTML and CSS first, then vanilla JavaScript.

I learn by building. Each project is a way to practise something new, from the DOM and events to browser storage and responsive layouts, and to find out where I get stuck. I’m also studying SQL and database concepts, and I’m drawn to interfaces that feel creative as well as useful.

My long-term aim is software engineering. I’m not there yet, and this site tries to be honest about that.

How the learning has gone, roughly in order

  1. Scratch. Block-based programming, with an MST certification.
  2. HTML5 and CSS3. Structure, styling and responsive layouts.
  3. Vanilla JavaScript. Functions, arrays, objects, classes and inheritance.
  4. Browser apps. DOM manipulation, events, localStorage and sessionStorage.
  5. SQL. Database concepts alongside the front-end work.

04 Projects that make the story real

Built to practise, shipped to share.

Four projects, each made to practise something specific. Every description sticks to what is on the live site or in the repository.

studora-uday.netlify.app

Student directory

Studora

A student directory for browsing, searching and adding student profiles. It was built to practise HTML, CSS and JavaScript on something that behaves like a real application.

  • Profile cards with a search box and a Load More button
  • An Add Student form with fields for class, stream, status and contact details
  • A detailed student profile view
  • A light and dark theme control
Why I built it
Practising HTML, CSS and JavaScript through an application-style project.
Built with
  • HTML
  • CSS
  • JavaScript

everestreserve.netlify.app

Online store concept

Everest Reserve

A responsive storefront concept for a Nepal-based online shop. The page lays out a hero banner, a product grid with prices and stock counts, a special-offers section with discount badges, service highlights, contact details and a newsletter sign-up.

  • Product grid and a separate special-offers row
  • Service highlights and contact section
  • Layout that adapts from phone to desktop
Why I built it
Practising storefront layout and responsive design. Product data on the page is sample content.
Built with
  • HTML
  • CSS
  • JavaScript

blinkitclonee.netlify.app

Quick-commerce homepage clone

Blinkit Clone

A front-end recreation of a quick-delivery grocery homepage, made for layout practice. It includes a delivery-time header with a location bar, a hero slider, product rows grouped by category with prices and add buttons, and a long footer directory of categories. It is an independent learning project, not affiliated with the real brand.

  • Category rows of product tiles with prices
  • Hero slider area and delivery-time header
  • Footer with a full category directory
Why I built it
Learning to recreate a dense, real-world interface with HTML and CSS.
Built with
  • HTML
  • CSS
